# AHB VIP – RTL Design

## Description
Developed an AHB-based Verification IP using SystemVerilog to validate bus transactions and protocol behaviour.

## Files Included
- master.sv
- slave.sv
- tb.sv
- test.sv
- ahb_rtl.sv

## Tools Used
- SystemVerilog
- ModelSim / Vivado

## Features
- AHB protocol verification
- Master-slave transaction validation
- Testbench-driven simulation

## Outcome
Successfully simulated and verified AHB protocol behaviour.
